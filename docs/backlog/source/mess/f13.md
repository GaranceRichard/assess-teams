# FEAT-061 — Installation automatisée

Repère cible **F13**, Feature de [EPIC-013 — Installation et exploitation MESS](e03-exploitation.md).

- **Enjeu / intention / valeur :** Garantir une installation reproductible sur un environnement vierge.
- **Acteurs :** exploitant MESS.
- **Capacité :** Installation automatisée dans le périmètre de préparation MESS, avec qualification des acquis avant toute correction.
- **Priorité :** P1 — préparation MESS après le premier parcours ; aucune priorité de Job.
- **Acquis et frontière :** Migrations et bootstrap Superadmin existants ; aucune installation MESS vierge prouvée.
- **Dépendances de Feature :** MEP-021, MEP-024 ; seuls les PBI consommateurs attendent ces prérequis.
- **Acceptation de Feature :** tous ses PBI satisfont leurs critères/refus et la DoD ; preuves intégrées, avancement calculé depuis le registre. Les acquis ne sont pas refaits.
- **Refus de Feature :** preuve manquante, gate échoué, capacité voisine supposée livrée ou arbitrage métier tranché implicitement empêchent sa livraison.
- **Suivi :** tailles recommandées, statuts et dates dans le [registre canonique de cette Epic](../../tracking/mess-e03.md). Aucune affectation de modèle implicite.

Les [règles communes MESS](../07-pre-mep.md#contrat-commun-des-pbi) s’appliquent à chaque PBI ci-dessous.

**Delta restant C+F :** préflight et répertoires idempotents (060), pose hors ligne (061), SQLite/bootstrap
explicite préservant une base existante (062), diagnostic sans faux succès (025). Migrations/health existants
sont réutilisés ; aucun installateur MESS déduit du bootstrap développeur. [Conditions de passage](../../planning/audit-20261027/trajectoire.md).

## MEP-060 — Préparer les répertoires et les paramètres d’installation

- **Identifiant / repère cible / Feature parente :** MEP-060 / 13.01 / FEAT-061 — Installation automatisée.
- **User story :** en tant que exploitant MESS, je veux préparer les répertoires et les paramètres d’installation afin de garantir une installation reproductible sur un environnement vierge.
- **Intention / description :** Préflight contrôle contrat, manifeste, droits et chemins persistants ; configuration préparée sans secret affiché ; relance conserve les données.
- **Origine / limite :** MEP-025 ; acquis et périmètre de cette Feature conservés. La [correspondance](../../planning/pre-mep-rapprochements.md) explicite le découpage.
- **Critères d’acceptation :** Préflight contrôle contrat, manifeste, droits et chemins persistants ; configuration préparée sans secret affiché ; relance conserve les données.
- **Vrais cas de refus :** Chemin invalide, droits absents ou empreinte incorrecte arrête avant modification destructive.
- **Dépendances / priorité :** MEP-024, MEP-021 / P1.
- **Valeur :** Garantir une installation reproductible sur un environnement vierge.
- **Taille recommandée / statut / date :** [entrée MEP-060 du registre canonique](../../tracking/mess-e03.md).
