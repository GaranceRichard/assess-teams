# FEAT-066 — Recette d’installation hors ligne

Repère cible **F18**, Feature de [EPIC-014 — Documentation, transfert et recette](e04-recette.md).

- **Enjeu / intention / valeur :** Démontrer le fonctionnement autonome sur un environnement vierge.
- **Acteurs :** exploitant MESS et responsable de recette.
- **Capacité :** Recette d’installation hors ligne dans le périmètre de préparation MESS, avec qualification des acquis avant toute correction.
- **Priorité :** P1 — préparation MESS après le premier parcours ; aucune priorité de Job.
- **Acquis et frontière :** Aucun PV de qualification MESS vierge enregistré ; builds locaux seuls insuffisants.
- **Dépendances de Feature :** MEP-025, MEP-028, MEP-030, MEP-031, MEP-063 ; seuls les PBI consommateurs attendent ces prérequis.
- **Acceptation de Feature :** tous ses PBI satisfont leurs critères/refus et la DoD ; preuves intégrées, avancement calculé depuis le registre. Les acquis ne sont pas refaits.
- **Refus de Feature :** preuve manquante, gate échoué, capacité voisine supposée livrée ou arbitrage métier tranché implicitement empêchent sa livraison.
- **Suivi :** tailles recommandées, statuts et dates dans le [registre canonique de cette Epic](../../tracking/mess-e04.md). Aucune affectation de modèle implicite.

Les [règles communes MESS](../07-pre-mep.md#contrat-commun-des-pbi) s’appliquent à chaque PBI ci-dessous.

**Travail E :** PV d’installation vierge (032) puis autonomie runtime hors Internet (068), sur candidat,
configuration et profil MESS identifiés. Tests/builds locaux ne sont pas ces recettes ; SMTP interne et
Internet restent distincts. [Entrées et sorties par PV](../../planning/audit-20261027/trajectoire.md), aucun développement métier inclus.

## MEP-032 — Installer Assess Teams sur un environnement vierge

- **Identifiant / repère cible / Feature parente :** MEP-032 / 18.01 / FEAT-066 — Recette d’installation hors ligne.
- **User story :** en tant que exploitant MESS et responsable de recette, je veux installer Assess Teams sur un environnement vierge afin de démontrer le fonctionnement autonome sur un environnement vierge.
- **Intention / description :** Installation du package exact sur cible vierge conforme sans réseau, Node/npm ou Docker ; configuration, migrations, statiques, comptes et health validés dans PV horodaté.
- **Origine / limite :** MEP-032 ; acquis et périmètre de cette Feature conservés. La [correspondance](../../planning/pre-mep-rapprochements.md) explicite le découpage.
- **Critères d’acceptation :** Installation du package exact sur cible vierge conforme sans réseau, Node/npm ou Docker ; configuration, migrations, statiques, comptes et health validés dans PV horodaté.
- **Vrais cas de refus :** Téléchargement nécessaire, prérequis absent ou intervention ad hoc ouvre une anomalie bloquante.
- **Dépendances / priorité :** MEP-025, MEP-028, MEP-031 / P1.
- **Valeur :** Démontrer le fonctionnement autonome sur un environnement vierge.
- **Taille recommandée / statut / date :** [entrée MEP-032 du registre canonique](../../tracking/mess-e04.md).
