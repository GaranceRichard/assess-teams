# FEAT-060 — Distribution autonome hors ligne

Repère cible **F12**, Feature de [EPIC-013 — Installation et exploitation MESS](e03-exploitation.md).

- **Enjeu / intention / valeur :** Produire un package installable sans téléchargement ni compilation frontend sur la cible.
- **Acteurs :** contributeur et exploitant MESS.
- **Capacité :** Distribution autonome hors ligne dans le périmètre de préparation MESS, avec qualification des acquis avant toute correction.
- **Priorité :** P1 — préparation MESS après le premier parcours ; aucune priorité de Job.
- **Acquis et frontière :** Build React, lockfiles, requirements, LICENSE et NOTICE existants. Le bootstrap de développement npm/pip ne vaut pas une distribution MESS.
- **Dépendances de Feature :** MEP-006, MEP-021, MEP-022, MEP-057, MEP-058, MEP-059 ; seuls les PBI consommateurs attendent ces prérequis.
- **Acceptation de Feature :** tous ses PBI satisfont leurs critères/refus et la DoD ; preuves intégrées, avancement calculé depuis le registre. Les acquis ne sont pas refaits.
- **Refus de Feature :** preuve manquante, gate échoué, capacité voisine supposée livrée ou arbitrage métier tranché implicitement empêchent sa livraison.
- **Suivi :** tailles recommandées, statuts et dates dans le [registre canonique de cette Epic](../../tracking/mess-e03.md). Aucune affectation de modèle implicite.

Les [règles communes MESS](../07-pre-mep.md#contrat-commun-des-pbi) s’appliquent à chaque PBI ci-dessous.

**Delta restant :** inventaire cible OS/CPU/ABI/versions/empreintes (057), build produit et assets locaux (058),
wheelhouse complet compatible (059), puis package/manifeste/notices (024). Sources et bootstrap développeur
ne constituent pas cette distribution. [Passages](../../planning/pre-mep.md) sur le profil de référence explicite ;
réassembler le candidat final avec services/outils livrés en aval, sans cycle 024↔063 ni résolution réseau cible.

## MEP-057 — Inventorier les dépendances nécessaires à la distribution

- **Identifiant / repère cible / Feature parente :** MEP-057 / 12.01 / FEAT-060 — Distribution autonome hors ligne.
- **User story :** en tant que contributeur et exploitant MESS, je veux inventorier les dépendances nécessaires à la distribution afin de produire un package installable sans téléchargement ni compilation frontend sur la cible.
- **Intention / description :** Inventaire backend, statiques, serveur, workers, ordonnanceurs et assets avec versions/empreintes/licences ; dépendances de build séparées des dépendances cible.
- **Origine / limite :** MEP-024 ; acquis et périmètre de cette Feature conservés. La [correspondance](../../planning/pre-mep-rapprochements.md) explicite le découpage.
- **Critères d’acceptation :** Inventaire fermé pour REF-WIN-01 : composants directs/transitifs, runtime/OS/CPU/ABI, serveur/frontal, statiques Swagger, workers et ordonnanceur ; versions exactes, provenance, empreintes et licences. Build et cible séparés ; compatibilités vérifiées ou incompatibilité précisément signalée, sans prétendre le site MESS qualifié.
- **Vrais cas de refus :** Composant obligatoire omis, résolution non reproductible, version/ABI incompatible ou droits de redistribution non établis rendent l’inventaire impropre au packaging ; un accord MESS n’est pas une entrée technique de cet inventaire.
- **Dépendances / priorité :** MEP-006 / P1.
- **Valeur :** Produire un package installable sans téléchargement ni compilation frontend sur la cible.
- **Taille recommandée / statut / date :** [entrée MEP-057 du registre canonique](../../tracking/mess-e03.md).
