# FEAT-060 — Distribution autonome hors ligne

Repère cible **F12**, Feature de [EPIC-013 — Installation et exploitation MESS](e03-exploitation.md).

- **Enjeu / intention / valeur :** Produire un package installable sans téléchargement ni compilation frontend sur la cible.
- **Acteurs :** contributeur et exploitant MESS.
- **Capacité :** Distribution autonome hors ligne dans le périmètre de préparation MESS, avec qualification des acquis avant toute correction.
- **Priorité :** P1 — préparation MESS après le premier parcours ; aucune priorité de Job.
- **Acquis et frontière :** Build React, lockfiles, requirements, LICENSE et NOTICE existants. Le bootstrap de développement npm/pip ne vaut pas une distribution MESS.
- **Dépendances de Feature :** MEP-006, MEP-021, MEP-022, MEP-054, MEP-055 ; seuls les PBI consommateurs attendent ces prérequis.
- **Acceptation de Feature :** tous ses PBI satisfont leurs critères/refus et la DoD ; preuves intégrées, avancement calculé depuis le registre. Les acquis ne sont pas refaits.
- **Refus de Feature :** preuve manquante, gate échoué, capacité voisine supposée livrée ou arbitrage métier tranché implicitement empêchent sa livraison.
- **Suivi :** tailles recommandées, statuts et dates dans le [registre canonique de cette Epic](../../tracking/mess-e03.md). Aucune affectation de modèle implicite.

Les [règles communes MESS](../07-pre-mep.md#contrat-commun-des-pbi) s’appliquent à chaque PBI ci-dessous.

**Delta restant :** inventaire cible OS/CPU/ABI/versions/empreintes (057), build produit et assets locaux (058),
wheelhouse complet compatible (059), puis package/manifeste/notices (024). Sources et bootstrap développeur
ne constituent pas cette distribution. [Passages](../../planning/audit-20261027/trajectoire.md) après profil approuvé ;
réassembler le candidat final avec services/outils livrés en aval, sans cycle 024↔063 ni résolution réseau cible.
