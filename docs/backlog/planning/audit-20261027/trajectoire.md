## Porte de sélection et natures

A qualification ; B correction ; C développement ; D arbitrage ; E recette cible ;
F documentation/livrable d’exploitation. Les natures coexistent et ne sont pas des statuts.
Le champ « entrées disponibles » décrit le présent ; il ne prétend pas que la sortie des dépendances
futures est disponible. La condition de sortie inclut leur disponibilité réelle, détaillée dans la fiche.
Aucune ligne C ou B ne vaut à elle seule autorisation de développement.

**Prêts pour développement complet à cette base : aucun PBI non réalisé sans réserve.**
TEAM-003 a un GET minimal préparables pour Admin/Superadmin, mais son découpage exige validation et
le PBI complet attend C04. TEAM-005 est une correction établie mais attend TEAM-003 ; les autres C
attendent décision ou livraison explicite. Cela n’interdit pas les qualifications ou préparations ci-dessous.

[Sorties 045](sortie-mep-045.md), [047](sortie-mep-047.md), [048](sortie-mep-048.md) :
aucun développement identifié. Elles se terminent sur un verdict borné, pas sur une amélioration sans fin.
047 avant 015 est maintenu comme ordre de collecte de preuves, sans arc technique ; un défaut lisible
reproduit passe devant. 048 peut être qualifié en parallèle de l’inventaire lexical 016. Pour F08, le risque
de confidentialité/perte/action inaccessible prime sur le rang ; [justification complète](ordonnancement-ux.md).
